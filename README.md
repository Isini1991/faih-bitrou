# Faih Bitrou — The way it felt.

Wedding photography portfolio concept for Faih Bitrou, in English.

- A short opening with a six-sided aperture, soft light, and a photograph coming into focus.
- A selected Santorini photograph that focuses while its button is held with a pointer or keyboard.
- Skip, Escape, and replay controls; shorter opening on mobile; reduced-motion support.
- Buildless HTML, CSS, and JavaScript with local image assets.

Live preview: https://isini1991.github.io/faih-bitrou/

The photographs are from the supplied photographer's public profile: https://www.instagram.com/faih_bitrou/

The opening appears once per browser. Select **Replay intro** to see it again. The inquiry links open the photographer's Instagram profile.

GitHub Pages serves the `main` branch from its root. No build or dependencies are required.
